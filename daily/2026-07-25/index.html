Spot the Injected Delimiter

A hands-on look at Agent Data Injection (ADI) — the attack that fools AI agents not by injecting instructions, but by faking the trusted data around them.

The idea: AI agents read structured context — JSON tool results, DOM elements, chat logs — full of fields the agent is told to trust: sender names, resource IDs, button labels. A 2026 paper found that attackers can smuggle fake delimiters (like "}, {"role":"system" or a spoofed closing tag) directly inside those "trusted" fields. The model doesn't parse delimiters with strict rules the way a real parser would — it guesses, probabilistically, based on what the text looks like. Get the guess wrong, and attacker-controlled text gets treated as if it came from the system itself.
