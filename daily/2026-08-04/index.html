🕳️ FaceHugger Sandbox

Three real CVEs, one misplaced security gate. Find where Hugging Face's trust_remote_code check needed to live — before they did.

Companion to today's post on the FaceHugger vulnerabilities (CVE-2026-44827, CVE-2026-45804, CVE-2026-44513) in Hugging Face Diffusers.

1. The pipeline load flow

Loading a Diffusers pipeline walks through these stages before any custom code runs:

① Config fetch
Read model_index.json from the Hub repo.
→
② Full repo download
Pull weights + any referenced pipeline / component files.
→
③ Local snapshot load
Same flow, but from an already-cached local directory.
→
④ Dynamic module load
get_cached_module_file() — the code actually gets exec'd here.

2. Pick where the trust_remote_code gate lives

Diffusers checks trust_remote_code at exactly one point in the flow. You choose where. Then throw all three real-world attacks at it.

Cross-repo custom pipeline
