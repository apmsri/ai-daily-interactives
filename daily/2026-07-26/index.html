The real attack chain

  • Initial access: attacker exploits CVE-2025-3248, an unauthenticated RCE in Langflow, an open-source LLM app/agent-building platform, on an internet-facing instance.
  • Reconnaissance: the agent enumerates the host and adapts on the fly — when a request returned XML instead of the JSON it expected, it restructured its parsing and kept going.
  • Credential harvesting: it hunts broadly across ecosystems at once — cloud provider keys, database credentials, crypto wallet files, and AI API keys — in a single sweep.
  • Self-correction: a failed privilege-escalation attempt is diagnosed and replaced with a working payload just 31 seconds later, no human involved.
  • Lateral movement: using a harvested SSH key, it pivots to a separate production server running MySQL and Alibaba's Nacos config service.
  • Impact: 1,342 Nacos configuration records are encrypted, the original tables are dropped, and a ransom note is left behind.
  • The giveaway: the note's Bitcoin address is the canonical example P2SH address copy-pasted across Bitcoin's own developer docs — not a wallet anyone controls. The encryption key itself was generated once and never saved anywhere, so paying wouldn't have recovered anything.

If you run agents or agent-adjacent infra, do this

  • Patch known CVEs in agent/orchestration frameworks (like Langflow) on the same day, not the same quarter — this one was flagged by CISA as actively exploited well before JadePuffer used it.
  • Never keep code-execution endpoints for agent platforms reachable from the open internet.
  • Don't co-locate AI orchestration servers with live cloud, database, or wallet credentials — put secrets in a dedicated manager the agent host can't read directly.
  • Watch for machine-paced behavior as a detection signal: hundreds of purposeful, varied payloads in minutes, and sub-minute error-to-fix cycles, are not typical of a human operator at the keyboard.
